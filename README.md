# 뭐하지?

> 지금 나에게 주어진 시간과 조건에서 **뭘 할지 빠르게 결정**하도록 돕는 앱

선택지를 잔뜩 늘어놓는 대신, 조건에 맞는 3~4개만 뽑아주고 그중 하나를 콕 집어 추천합니다.

## 쓰는 법

1. 홈 화면의 **"뭐하지?"** 버튼을 누른다
2. 지금 조건을 고른다 — 시간 / 예산 / 위치 / 혼자·같이 / 기분 / 빼고 싶은 것
3. 티켓이 나오면 **"🎯 고민 그만, 이걸로 결정!"** 을 누르거나, 마음에 드는 걸 시간표에 담는다
4. 완성한 시간표는 이미지로 저장·공유할 수 있다

## 기능

- **조건 기반 추천** — 시간·예산·장소·동행·기분을 조합해 168개 활동에서 골라냄
- **개인화** — MBTI 16유형과 나이를 저장해두면 성향에 맞는 활동이 우선 노출
- **범주 제외** — 돈 쓰는 것, 야외, 운동, 술 등 10가지 범주를 미리 뺄 수 있음
- **추천 이유** — 항목을 누르면 왜 이걸 골랐는지 조건별로 설명
- **시간표** — 고른 활동을 30분 단위 슬롯에 담고 이미지로 저장·공유
- **오프라인 동작** — 인터넷이나 AI 키가 없어도 추천이 그대로 작동

## AI 추천 (선택)

키 없이도 다 작동하지만, 본인의 AI 키를 넣으면 날씨·영업시간까지 반영한 실시간 추천을 받을 수 있습니다.

- 상단 **🤖 AI** 버튼 → 서비스 선택 → 키 입력
- **Google Gemini**: [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서 무료 발급
- **Anthropic**: 유료 크레딧 필요

키는 브라우저(`localStorage`)에만 저장되며 어디로도 전송되지 않습니다.

## 실행

빌드가 필요 없습니다. `index.html`을 브라우저로 열면 끝.

```bash
# 로컬 서버로 보려면
python3 -m http.server 8000
# → http://localhost:8000
```
